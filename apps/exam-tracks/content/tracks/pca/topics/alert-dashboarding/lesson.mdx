## The expression browser

Every Prometheus server has a built-in UI, the **expression browser**, at `/query` (`/graph` in 2.x). Type any PromQL expression and see:

- **Table**: an **instant query**, one value per series right now.
- **Graph**: a **range query**, values over time.

The docs position it for **ad-hoc queries and debugging**. For lasting dashboards, use Grafana.

## Grafana

**Grafana** is the standard way to build dashboards on Prometheus data. It has shipped a Prometheus data source since **Grafana 2.5.0** (2015).

Getting started, per the docs:

1. Grafana listens on **`http://localhost:3000`**, and the default login is `admin` / `admin`.
2. Add a **data source** of type Prometheus with your server's URL, such as `http://localhost:9090/`, then Save & Test.
3. Add a panel, choose the Prometheus data source and enter a **PromQL query**.
4. Name series with the **legend format**, using label templates:

```text
{{method}} - {{status}}
```

5. Inside `rate()` and `increase()`, Grafana recommends its **`$__rate_interval`** variable rather than a hard-coded window.

You can also **import pre-built dashboards** from grafana.com (filtered to the Prometheus data source), pointing their `datasource` entries at your own data source.

## Building panels that hold up

A typical request-rate panel:

```promql
sum by (code) (rate(http_requests_total[$__rate_interval]))
```

- **Graph rates, not raw counters.** A raw counter only climbs.
- **Check the size first.** The querying docs advise building new queries in the **table view** until the result is reasonable (hundreds, not thousands, of series), and only then graphing.
- **Precompute heavy panels.** If an expression is slow, or many dashboards re-run it on every refresh, store it with a **recording rule** and query that.

## Other options

- **Console templates** are Go templates served by Prometheus itself. Since Prometheus 3.0 they're **no longer bundled**, and you supply your own with `--web.console.templates` and `--web.console.libraries`. The docs suggest newcomers start with Grafana.
- **Perses** is an open-source, dashboards-as-code tool with native Prometheus support, documented as an alternative.
